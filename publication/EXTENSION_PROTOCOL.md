# Publication robustness extension

The original three-split results were already known when this extension was specified. This is a post-audit sensitivity analysis, not preregistration or independent confirmation. Ten fixed seeds are 42, 17, 2026, 7, 101, 211, 307, 401, 503, 601. Retain the same model configurations, calibration, partitions, selection objectives, five-percentage-point senior TPR tolerance, economic scenarios and bootstrap procedure. Report every split; do not select seeds by favorable outcomes. No new dataset is introduced. The original three-split results are preserved inside archive/superseded_work.zip. The ten-split extension is the current study in results/, configured by config/study.json.

Primary descriptive endpoint: proportion of these ten test splits whose absolute senior TPR gap exceeds 0.05 after satisfying that constraint on validation. Secondary endpoints: paired scenario-profit differences, calibrated score metrics, economic sensitivity, and calibration/feature ablations. Overlapping splits are not independent trials; do not compute a binomial confidence interval or naive t-test from the split failure count. Bootstrap intervals remain conditional on the fixed fitted policy and empirical demographic/label counts.
